# NOCTIS
### A library of experiences.

A digital museum for discovering and collecting cultural experiences.

Books, films, games, music, photography, and art come together in an interface inspired by a museum at midnight — with cinematic atmosphere, fluid navigation, and real cultural works.

**[Explore NOCTIS ↗](https://noctis-dalva1.vercel.app/)**

## Step inside the archive

- **Six cultural rooms**, each with its own visual identity.
- **Interactive books**, featuring opening animations and browsable pages.
- **Discovery and curation**, with search, filters, quick previews, and exhibitions.
- **Your personal archive**, with saved works, private ratings, and custom collections.

Built with responsive layouts, keyboard navigation, and reduced-motion preferences in mind.

## Built with

React · TypeScript · Vite · CSS Modules · Motion for React · React Router · Lucide
